```{dropdown} Use of prompt symbols in this documentation
:icon: terminal

Prompt symbols on this page are used to distinguish between commands that
you run in PowerShell and commands that you run in Ubuntu:

* `PS>`: PowerShell
* `$`: Ubuntu

When you copy a command, only the command is copied — the prompt symbol and
any output are not included.
```
